# CodeAlpha_HangmanGame

Text-based Hangman for the CodeAlpha Python internship (Task 1).

## What it does
- Picks one word at random from a list of 5 predefined words.
- Player guesses one letter at a time.
- Game ends after 6 wrong guesses, or when the word is complete.

## How to run
```bash
python hangman.py
```

## Concepts used
`random`, `while` loop, `if-else`, strings, lists/sets.
